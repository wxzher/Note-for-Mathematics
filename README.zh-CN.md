## 高等数学

共 12 章，主要参考同济大学《高等数学》教材。

| 章节 | 内容 |
|:---:|------|
| 01 | 函数与极限——函数性质、极限定义、无穷小与连续性 |
| 02 | 导数与微分——求导法则、隐函数求导、参数方程 |
| 03 | 微分中值定理及其应用——罗尔定理、拉格朗日中值定理、柯西中值定理、洛必达法则、泰勒展开 |
| 04 | 不定积分——换元积分法、分部积分法、有理函数积分 |
| 05 | 定积分——黎曼和、微积分基本定理、反常积分 |
| 06 | 定积分的应用——面积、体积、弧长、旋转曲面面积 |
| 07 | 微分方程——可分离变量方程、线性方程、齐次方程、高阶常微分方程 |
| 08 | 空间解析几何与向量代数——向量、平面、直线、曲面与空间曲线 |
| 09 | 多元函数微分法及其应用——偏导数、全微分、极值及其应用 |
| 10 | 二重积分——直角坐标与极坐标、积分次序交换及应用 |
| 11 | 曲线积分与曲面积分——数量值与向量值积分、格林公式、高斯公式、斯托克斯公式 |
| 12 | 无穷级数——数项级数、幂级数、傅里叶级数 |

**补充资料**：伯努利不等式。  
**练习资料**：极限 100 题、导数 100 题、积分 100 题、导数与积分公式手册、综合复习指南。

## 数值最优化

主要参考陈宝林《最优化理论与算法》（第 2 版），包含若干选定章节的 11 份课程笔记、5 次作业和 2 个计算实验。

| 章节 | 内容 |
|:---:|------|
| 01 | 预备知识——中值定理、泰勒展开、柯西–施瓦茨不等式、凸集与凸函数 |
| 07 | 最优性条件——KKT 条件、约束规范、一阶与二阶条件 |
| 08 | 算法基础——收敛速度、终止准则、线搜索、信赖域 |
| 09 | 一维搜索——黄金分割法、斐波那契法、二分法、插值法、Wolfe 条件 |
| 10 | 使用导数的无约束优化——最速下降法、牛顿法、拟牛顿法（BFGS/DFP）、共轭梯度法 |
| 12 | 可行方向法——Zoutendijk 法、Rosen 梯度投影法、简约梯度法 |
| 13 | 罚函数法——外点罚函数（SUMT）、内点罚函数（障碍法）、增广拉格朗日法 |
| 14 | 二次规划——有效集法、Lemke 法、Wolfe 法 |

**补充资料**：无约束一维搜索、中值定理与泰勒展开及柯西不等式复习。

**作业**（共 5 次）：

- HW1–HW2：凸集、最优性条件、KKT 系统
- HW3：一维搜索方法
- HW4：梯度类方法（最速下降法、牛顿法、拟牛顿法）
- HW5：约束优化（罚函数法、二次规划）

**实验**：

- **实验 1——梯度下降方法**：在二维和四维修正 Rosenbrock 函数上比较精确／非精确最速下降法、牛顿法和信赖域法
- **实验 2——优化方法比较**：在 10 个测试问题上比较 10 种方法的迭代次数、函数计算次数与收敛成功率
